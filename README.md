# はじめての囲碁

囲碁をまったく知らない人が、iPhone の Safari で遊びながら覚えるためのアプリです。
通信・外部ファイル・インストールは不要で、`index.html` を開けば動きます。

## 使い方

- **はじめての囲碁（用語レッスン）**：呼吸点・アタリ・取る・自殺手（着手禁止点）・コウ・地の6つを、図と短い説明、すぐ試せる問題1問ずつで覚えます。
- **石を取る練習**：アタリの白石を取る問題が5問あります。
- **対局する**：9路盤で、あなた（黒）とコンピュータ（白）が打ちます。コンピュータはわざと弱くしてあります。
  - 石は「二度タップ」で置きます。1回目で半透明の石が出て、同じ点をもう一度タップすると置けます。打てない点（石がある・自殺手・コウ）は1回目で仮の石が赤くなり、理由が出ます。
  - 「待った」で1手戻し（コンピュータが考えている間も戻せます）、「パス」でパス、「最初から」で新しい対局にします。2人続けてパスすると終局です。
  - 終局したら、死に石（囲いの中に取り残された石）をタップして×の印を付け（つながった石ごと。もう一度で外れます）、「数える」を押します。自分（黒）の石に印を付けようとすると確認が出ます。黒の石に印が残ったまま「数える」を押すと、その数を示して、そのまま数えるか戻るかを選べます。
  - 数え方は日本のルールと同じ「地＋アゲハマ」です。印を付けた死に石は取り除いて、相手のアゲハマに加えます。コミはありません。
  - セキ（どちらも相手の石を取れないまま、両方とも生きている形）の数え方には対応していません。
  - **爺の指南**：困ったら押すと、お目付け役の爺やが1手だけ教えます（盤に緑の二重丸、上に理由）。もう一度押すか、石を置くと消えます。仮の石があるときに押すと、仮の石は消えて指南が出ます。白が考えている間と終局後は押せません。教える順番は次のとおりです。自殺手・コウで打てない点は出しません。決まった正解ではなく、目安です。
    1. **取る・逃げるを比べる**：アタリの白を取る手（値＝取れる白の数＋その手で助かる黒の数）と、アタリの黒を逃がす手（値＝助かる黒の石の数）を1つの表で比べ、値の大きいほうを教えます（同じなら取る手）。取った直後にそれより多く取り返される手（ウッテガエシ）は教えません。1子を取り1子で取り返される形（打った黒も1子）だけに「コウで取り返される恐れ」と添え、それ以外で取り返される手には「取り返される恐れがありますぞ」と添えます（このときは「黒も助かります」とは言いません）。逃げた後の呼吸点が2つのときは簡単なシチョウを読み（深さ60手まで）、取られるなら逃げる手として教えません。
    2. **白の呼吸点を減らす**：打った黒の呼吸点が3つ以上残る手だけ。
    3. **広い所**：周りの石が少なく、天元に近い点。
    - 2と3では、1線（盤の端の列・行）と、どちらかの地の点は教えません。同じ値なら天元に近い点を選びます。地の決め方：盤に黒と白の両方の石があるとき、片方の色の石にしか接していない空き点のつながりを、大きさにかかわらず地とみなします（黒しか無い序盤は地とみなさず、広い所を教えます）。
    - **境界点**：黒と白の両方の石に接する空き点です。境目が1か所だけ開いていると空き点が盤全体でつながってしまうので、大きなつながりは境界点を除いて分け直します。分けた所がどれも片方の色にだけ接し、境目の石がどれも自分の地に呼吸点2つ以上で接していれば、分けた所を地、境界点をダメとみなします（隅の1子のように地を持たない石が境目にいる序盤は、分けずに広い所のままにします）。
    - **終盤**：広い所が残っておらず、境界点が盤の2辺ぶん（9路で18点）以下のとき。終盤では2と3は白の石に接している点（ダメ詰め・境目）だけを教え、この点は1線でもかまいません。3の文は「境目を閉じなされ。ダメを詰める手でございます」になります。終盤でなければ1線は教えません。
    - **手入れ**：黒がパスしたら白に取られる・アタリにされる所があれば、それを防ぐ点を「手入れが要りますぞ」と教えます（終盤は2・3より先、それ以外はパスをすすめる前に調べます）。白がそこに打つと白の石が呼吸点1つになり、黒がすぐ取れる（ウッテガエシにならない）所は数えません。候補が複数あるときは、境界点や白の打つ点そのものを、黒地の中の点より先に教えます。
    - 打てる点が全部 地・1線・自分の目・打つと自分がアタリになる点なら「パス」をすすめます。ダメが残っていれば「残りはダメと地ばかり」、無ければ「どちらかの地ばかり」と言います。逃げても助からないアタリの黒があるときは、その旨を先に添えます。
    - 設計メモ：打ち込み（相手の大きな地の中での生き）は考えません。白が大きく囲った空き点も白地とみなし、パスをすすめることがあります。
- 赤い点線の付いた言葉はタップすると説明が出ます。
- 進み具合はブラウザ（localStorage）に保存されます。メニュー下の「進み具合をリセット」で消せます。

### iPhone で開くには

Mac で次の1行を実行し、同じ Wi‑Fi の iPhone の Safari で `http://<MacのIPアドレス>:8000/` を開きます。

```
cd ~/ClaudeDocument/go-trainer && python3 -m http.server 8000
```

**注意**：この方法で開いている間は、同じ Wi‑Fi にいる人なら誰でもこのフォルダの中身を見られます。遊び終わったら、実行したターミナルで `control` キーを押しながら `C` を押して止めてください。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の土台 |
| `style.css` | 見た目（iPhone 縦画面優先） |
| `app.js` | 画面と操作（盤の描画・ボタン・小窓） |
| `game.js` | 対局の進め方（DOM を使わない。二度タップ・待った・コンピュータの手番とタイマー・保存と再開・死に石の印と数える） |
| `hint.js` | 爺の指南（DOM を使わない純粋な関数。局面から1手すすめる。乱数は使わない） |
| `rules.js` | 囲碁のルール（DOM を使わない純粋な関数。取る・自殺手・コウ・パス・死に石・数え方） |
| `lessons.js` | 用語レッスン6つと「石を取る」練習5問のデータ |
| `rules.test.js` | ルールと問題データのテスト |
| `game.test.js` | 対局の進め方のテスト（偽物のタイマーで時間を進める） |
| `app.test.js` | 画面側（app.js）のテスト（追加のインストール不要。node の中に偽の画面部品を作って読み込む） |
| `hint.test.js` | 爺の指南のテスト |
| `mutate.check.js` | テストの効き目の確認用（直した箇所をメモリ上で壊して、テストが失敗するかを見る） |

## テストの実行方法

次の4つを実行し、どれも最後に「0 件失敗」と出れば合格です。

```
cd ~/ClaudeDocument/go-trainer && node rules.test.js && node game.test.js && node app.test.js && node hint.test.js
```

- `rules.test.js`：取る・複数の連を同時に取る・自殺手の禁止・相手を取れる自殺手形は打てる・コウの禁止・別の手の後なら取り返せる・うってがえし・終局の数え方（地＋アゲハマ、死に石入り）に加え、レッスンと練習問題の答えがルールどおり正しいかも確かめます。
- `game.test.js`：二度タップ、打てない点の赤表示、待った、コンピュータの手番がタイマーの重なりで2回走らないこと（メニューへ出てすぐ戻る場合の回帰テスト）、保存からの再開（保存データの死に石の一覧がおかしいときに捨てること）、終局後の死に石の印と数え方、黒の石に印を付けるときの確認と数える前の確認を確かめます。
- `app.test.js`：画面の出入りで白が2回打たないこと、考え中の「待った」「最初から」、打てない点の赤表示、死に石の確認の小窓、隅の輪が盤からはみ出さないこと、「爺の指南」の出し入れ（押すと印と文が出て、もう一度で消える・打つと消える・考え中は押せない・仮の石があるときは仮の石を消して指南を出す）を確かめます。HTML を本当に解釈してはいないので、見た目そのものは確かめられません。
- `hint.test.js`：爺の指南の優先順位（取る→逃げる→減らす→広い所）、コウの文と取り返しの文、大きな地へ打ち込まないこと、境界点（1線の境目が開いた局面）、手入れ（要らない手入れを勧めないこと・候補の順位）、終盤の文、パスの文、10以上の数を「個」と言うこと、指南1回の重さ、逃げても呼吸点が増えない手・自分がアタリになる手・自殺手・コウの点・自分の目を出さないこと、打つ所がないとき・白番のときの答え、盤や待ったの履歴を変えないこと、爺の口調を確かめます。
