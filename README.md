# はじめての囲碁

囲碁をまったく知らない人が、iPhone の Safari で遊びながら覚えるためのアプリです。
通信・外部ファイル・インストールは不要で、`index.html` を開けば動きます。

## 使い方

- **はじめての囲碁（用語レッスン）**：呼吸点・アタリ・取る・自殺手（着手禁止点）・コウ・地の6つを、図と短い説明、すぐ試せる問題1問ずつで覚えます。
- **石を取る練習**：アタリの白石を取る問題が5問あります。
- **対局する**：9路盤で、あなた（黒）とコンピュータ（白）が打ちます。コンピュータはわざと弱くしてあります。
  - 石は「二度タップ」で置きます。1回目で半透明の石が出て、同じ点をもう一度タップすると置けます。打てない点（石がある・自殺手・コウ）は1回目で仮の石が赤くなり、理由が出ます。
  - 「待った」で1手戻し（コンピュータが考えている間も戻せます）、「パス」でパス、「最初から」で新しい対局にします。2人続けてパスすると終局です。
  - 終局したら、死に石（囲いの中に取り残された石）をタップして×の印を付け（つながった石ごと。もう一度で外れます）、「数える」を押します。自分（黒）の石に印を付けようとすると確認が出ます。黒の石に印が残ったまま「数える」を押すと、その数を示して、そのまま数えるか戻るかを選べます。
  - 数え方は日本のルールと同じ「地＋アゲハマ」です。印を付けた死に石は取り除いて、相手のアゲハマに加えます。コミはありません。
  - セキ（どちらも相手の石を取れないまま、両方とも生きている形）の数え方には対応していません。
- 赤い点線の付いた言葉はタップすると説明が出ます。
- 進み具合はブラウザ（localStorage）に保存されます。メニュー下の「進み具合をリセット」で消せます。

### iPhone で開くには

Mac で次の1行を実行し、同じ Wi‑Fi の iPhone の Safari で `http://<MacのIPアドレス>:8000/` を開きます。

```
cd ~/ClaudeDocument/go-trainer && python3 -m http.server 8000
```

**注意**：この方法で開いている間は、同じ Wi‑Fi にいる人なら誰でもこのフォルダの中身を見られます。遊び終わったら、実行したターミナルで `control` キーを押しながら `C` を押して止めてください。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の土台 |
| `style.css` | 見た目（iPhone 縦画面優先） |
| `app.js` | 画面と操作（盤の描画・ボタン・小窓） |
| `game.js` | 対局の進め方（DOM を使わない。二度タップ・待った・コンピュータの手番とタイマー・保存と再開・死に石の印と数える） |
| `rules.js` | 囲碁のルール（DOM を使わない純粋な関数。取る・自殺手・コウ・パス・死に石・数え方） |
| `lessons.js` | 用語レッスン6つと「石を取る」練習5問のデータ |
| `rules.test.js` | ルールと問題データのテスト |
| `game.test.js` | 対局の進め方のテスト（偽物のタイマーで時間を進める） |
| `app.test.js` | 画面側（app.js）のテスト（追加のインストール不要。node の中に偽の画面部品を作って読み込む） |
| `mutate.check.js` | テストの効き目の確認用（直した箇所をメモリ上で壊して、テストが失敗するかを見る） |

## テストの実行方法

次の3つを実行し、どれも最後に「0 件失敗」と出れば合格です。

```
cd ~/ClaudeDocument/go-trainer && node rules.test.js && node game.test.js && node app.test.js
```

- `rules.test.js`：取る・複数の連を同時に取る・自殺手の禁止・相手を取れる自殺手形は打てる・コウの禁止・別の手の後なら取り返せる・うってがえし・終局の数え方（地＋アゲハマ、死に石入り）に加え、レッスンと練習問題の答えがルールどおり正しいかも確かめます。
- `game.test.js`：二度タップ、打てない点の赤表示、待った、コンピュータの手番がタイマーの重なりで2回走らないこと（メニューへ出てすぐ戻る場合の回帰テスト）、保存からの再開（保存データの死に石の一覧がおかしいときに捨てること）、終局後の死に石の印と数え方、黒の石に印を付けるときの確認と数える前の確認を確かめます。
- `app.test.js`：画面の出入りで白が2回打たないこと、考え中の「待った」「最初から」、打てない点の赤表示、死に石の確認の小窓、隅の輪が盤からはみ出さないことを確かめます。HTML を本当に解釈してはいないので、見た目そのものは確かめられません。
